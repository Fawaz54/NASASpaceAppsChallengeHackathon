# Sources

Every threshold, protocol step and dataset the app uses goes here.
Judges score scientific validity, so nothing ships with an empty source.

## Where to look

- NASA Technical Reports Server: https://ntrs.nasa.gov
- NASA Open Science Data Repository: https://osdr.nasa.gov
- DONKI space weather events: https://ccmc.gsfc.nasa.gov/DONKI-API/get/SEP
- Curiosity RAD radiation data: https://pds-ppi.igpp.ucla.edu/data/MSL-M-RAD-3-RDR-V1.0/
- NASA Life Sciences Data Archive (catalog; astronaut-level data is restricted)
